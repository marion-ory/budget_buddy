        BUDGET BUDDY💰

Budget Buddy est une application de gestion financière personnelle développée en Python. Elle permet aux utilisateurs de suivre leurs transactions, de gérer leur budget via une interface graphique sécurisée et de visualiser l'état de leurs comptes en temps réel.

  Fonctionnalités:
  
    🔒 Sécurité & Authentification
    
Module de connexion : Accès sécurisé à l'espace personnel.

Inscription : Création de compte avec validation stricte du mot de passe (min. 10 caractères, majuscule, minuscule, chiffre et caractère spécial).

Protection des données : Hachage des mots de passe en base de données pour une sécurité optimale.

    📊 Gestion des Transactions
    
Opérations bancaires : Ajouter des revenus (dépôts), des dépenses (retraits) et effectuer des transferts.

Historique complet : Visualisation de toutes les transactions avec référence, description, montant et date.

Recherche avancée : Filtrage multi-critères (par date, plage de dates, catégorie ou type) et tri par montant.


    📈 Tableau de Bord (Dashboard)
    
Vue globale : Récapitulatif du solde actuel et des dépenses mensuelles.

Visualisation : Graphiques représentatifs des flux financiers.

Alertes : Système de notifications en cas de découvert ou d'événements importants.

    🏦 Espace Banquier (Bonus)
    
Gestion multi-clients par un ou plusieurs banquiers.

Possibilité pour le banquier d'effectuer des opérations au nom du client.


    🛠️ Compétences Techniques
    

Langage : Python 3.x

Interface Graphique : Pygame / Tkinter / PyQt (à adapter selon ton choix)

Base de données : SQL (SQLite ou PostgreSQL)

Sécurité : Algorithmes de hachage (ex: hashlib ou bcrypt)
